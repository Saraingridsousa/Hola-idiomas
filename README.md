# ¡Hola! Idiomas

Uma escola de idiomas fictícia, criada como projeto de portfólio. Toda conexão começa com um olá.

## Proposta
Uma experiência educacional responsiva para diferentes idades, com descoberta de cursos, recomendações personalizadas e atividades demonstrativas.

## Desenvolvimento
- React, TypeScript e Vite.
- Identidade visual própria, colorida e acessível.
- Sem backend nesta versão; nenhuma matrícula ou reserva é real.

## Executar localmente
Após a configuração da aplicação, execute `npm install` e `npm run dev`.
